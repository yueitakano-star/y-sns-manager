# Googleドライブ連携の設定（読み取り専用・約30分）

「過去素材置き場」で、ドライブのフォルダを指定してまとめて取り込むための設定です。
**サービスアカウント**（読み取り専用のロボット用アカウント）を作り、取り込みたいフォルダをそのロボットに共有します。
OAuthの審査・認証の期限切れはありません。個人のGoogleアカウントで使えます。

できること／できないこと

- できる: フォルダの中のファイル名・種類・作成日・サムネイルを読み取り、リンクとして登録する
- しない: ファイルの変更・削除・コピー（読み取り専用の権限しか持たせません）

## 手順

### 1. Google Cloud でプロジェクトを作る
1. https://console.cloud.google.com を開き、ドライブを持つ Google アカウントでログイン（初回は利用規約に同意）
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `y-sns-manager` など → 作成

### 2. Google Drive API を有効にする
1. 左メニュー「APIとサービス」→「ライブラリ」
2. 「Google Drive API」を検索 → 開く →「有効にする」

### 3. サービスアカウントを作る
1. 左メニュー「IAMと管理」→「サービスアカウント」→「サービスアカウントを作成」
2. 名前: `y-sns-reader`（何でも可）→「作成して続行」
3. 「ロール」は**何も選ばず**「続行」→「完了」
4. 一覧に出た `y-sns-reader@…iam.gserviceaccount.com` が、**フォルダの共有先アドレス**です（後で使います）

### 4. 鍵（JSON）を作る
1. 作成したサービスアカウントをクリック →「キー」タブ →「鍵を追加」→「新しい鍵を作成」
2. 形式は **JSON** →「作成」→ JSONファイルがダウンロードされます
   - 「組織のポリシーで禁止されています」と出る場合は、個人アカウントのプロジェクトで作り直してください

### 5. Vercel に設定する
JSONの中身は長いので、**Base64に変換**して入れると貼り付けで崩れません。

PowerShell で（`C:\...\key.json` はダウンロードしたファイルの場所）:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\...\key.json")) | Set-Clipboard
```

1. Vercel → プロジェクト → Settings → Environment Variables
2. Key: `GOOGLE_SERVICE_ACCOUNT_JSON` / Value: クリップボードの内容を貼り付け / **Sensitive** にチェック / Environment: Production
3. 保存 → Deployments の最新を **Redeploy**
4. 設定後、ダウンロードしたJSONファイルは**削除**してください（鍵はVercelにだけ残します）

### 6. フォルダを共有する
1. ドライブで取り込みたいフォルダを右クリック →「共有」
2. 手順3のアドレス（`…@…iam.gserviceaccount.com`）を入力 → 権限は **閲覧者** →「通知を送信」のチェックを外して「共有」
   - 上位のフォルダ（例: 「過去素材」）を1つ共有すれば、中のフォルダ・ファイルも読めます

### 7. 取り込む
1. サイトで店舗を選ぶ →「素材」→「過去素材置き場」→「📥 ドライブのフォルダから取り込み」
2. 共有先アドレスが画面に表示されていれば設定は反映されています
3. フォルダのURLを貼る →「フォルダを読み取る」→ 一覧を確認 → 取り込む

## 止めたい／鍵が漏れたとき
- Google Cloud のサービスアカウントの「キー」タブで、その鍵を**削除**すれば、すぐに使えなくなります
- 共有を外すだけでも、そのフォルダは読めなくなります

## 環境変数（開発・テスト用）
- `GOOGLE_DRIVE_API_BASE` / `GOOGLE_TOKEN_URL` は、テストで偽サーバーに向けるためのものです。本番では設定しません。
